# Comprehensive Technical Glossary

### A
- **Accessible Perceptual Contrast Algorithm (APCA):** An advanced, perception-based contrast prediction algorithm developed for W3C WCAG 3.0. Used to calibrate FactStamp's `Saffron Sleek` palette to ensure body text achieves $|L^c| \ge 75$.
- **Agreement Ratio ($A$):** Normalized percentage ($0–100\%$) representing the fraction of participating verifiers who voted for the majority verdict candidate ($A = \frac{N_{\text{majority}}}{N_{\text{total}}} \times 100$). Weighted at $40\%$ in the consensus confidence formula.

### C
- **Client-Side Rasterization:** The compilation of DOM tree structures into raster pixel grids (PNG) directly in the browser using SVG `<foreignObject>` canvas rendering without cloud server intervention.
- **Cloud Firestore:** Google Cloud's managed NoSQL document database providing real-time WebSocket listeners (`onSnapshot`) and declarative security rules.
- **Confidence Score ($C$):** Composite percentage rating ($0–100\%$) indicating verdict certainty, computed via $C = 0.40A + 0.30R + 0.30S$.
- **Contested Claim:** Status assigned when a claim experiences a split vote and cannot reach majority consensus within 7 days.

### D
- **Dark Social:** Communication in private, encrypted, or closed messaging channels (such as WhatsApp) that cannot be crawled by search engines or public web tools.
- **Data Flow Diagram (DFD):** Visual modeling notation illustrating the functional flow and transformations of data through system processes.

### E
- **End-to-End Encryption (E2EE):** Cryptographic protocol ensuring messages are readable only by the communicating endpoints. Respected completely by FactStamp's user-directed submission model.

### F
- **ForeignObject (SVG `<foreignObject>`):** An SVG element that allows arbitrary HTML/CSS nodes to be embedded and rendered within an SVG canvas.

### H
- **HTML5 Canvas API:** Browser interface for dynamic 2D pixel manipulation, used in FactStamp for client-side screenshot compression ($< 250$ KB).

### I
- **IndicBERT:** Pre-trained multilingual transformer model covering 12 Indian languages, planned for cross-lingual duplicate detection.

### J
- **Jaccard Similarity Index:** Set-theoretic metric defined as $J(A, B) = \frac{|A \cap B|}{|A \cup B|}$, used to detect duplicate forwards with $96.4\%$ accuracy ($J \ge 0.75$).

### N
- **NoSQL Document Database:** Non-relational database storing semi-structured JSON documents inside collections.

### O
- **OKLCH / Oklab Color Space:** Perceptually uniform cylindrical color space specifying Lightness, Chroma, and Hue, used for FactStamp's design tokens.
- **Optical Character Recognition (OCR):** Computational extraction of machine-encoded text from images, executed via in-browser Tesseract.js WebAssembly.

### P
- **Progressive Web App (PWA):** Web application architecture supporting offline caching, background synchronization, and app-like installation.

### Q
- **Quorum Consensus:** Distributed decision protocol requiring a minimum of three independent verifier reviews ($N \ge 3$) before a verdict is finalized.

### R
- **Recharts:** Declarative React-native SVG charting library used for FactStamp's analytics dashboard.
- **Reputation Score ($R$):** Dynamic $0–100$ score tracking a verifier's historical accuracy, weighted at $30\%$ in the consensus formula.
- **Role-Based Access Control (RBAC):** Security system restricting access based on user privilege tiers (`User`, `Verifier`, `Admin`).

### S
- **Saffron Sleek Design System:** Bespoke UI system combining Sleek precision, Deep Saffron primary tones, warm cream surfaces, and DM Sans typography, free from generic purple AI aesthetics.
- **Service Worker:** Background browser worker enabling client-side caching and offline background sync.
- **Small Language Model (SLM):** Lightweight quantized generative neural network (100M–2B parameters) capable of edge execution via WebGPU.
- **Source Credibility Score ($S$):** Domain authority rating of cited evidence (Tier 1 High: 100, Tier 2 Medium: 70, Tier 3 Low: 30), weighted at $30\%$ in consensus.
- **Sybil Attack:** Adversarial attack where a single entity generates multiple fake accounts to subvert reputation and consensus.

### T
- **Tesseract.js:** Pure WebAssembly/JavaScript port of the Tesseract OCR engine running in browser workers.
- **Trust Ring:** SVG circular progress ring rendered around verifier avatars indicating reputation on a 0–100 scale.

### V
- **Verdict Stamp:** Color-coded visual badge indicating verified status (`TRUE`, `FALSE`, `MISLEADING`, `UNVERIFIABLE`, `CONTESTED`).
- **Vite:** High-performance frontend build tool utilizing native ESM and sub-50ms HMR.

### W
- **WebAssembly (WASM):** Binary instruction format allowing high-performance C/C++/Rust code (such as OCR and Whisper engines) to run in the browser.
- **WebGPU:** Modern web API providing hardware-accelerated compute directly to browser applications.
- **Work Breakdown Structure (WBS):** Hierarchical decomposition of project deliverables across sprints and milestones.
