## Summary of Available Templates

1. **[`srs_template-ieee.md`](file:///home/aadish/Documents/typst/FactStamp/template/srs_template-ieee.md)** — Official IEEE Std 830-1998 Software Requirements Specification template.
2. **[`2020-Scrum-Guide-US.md`](file:///home/aadish/Documents/typst/FactStamp/template/2020-Scrum-Guide-US.md)** — Official 2020 Scrum Guide by Ken Schwaber & Jeff Sutherland.
3. **[`SCRUM_Model.md`](file:///home/aadish/Documents/typst/FactStamp/template/SCRUM_Model.md)** — Scrum roles, artifacts, sprint events, & ceremony reference.
4. **[`SDLC_Software_Process_Models.md`](file:///home/aadish/Documents/typst/FactStamp/template/SDLC_Software_Process_Models.md)** — Waterfall, Spiral, V-Model, Iterative, & Agile process models.
5. **[`Extreme_Programming.md`](file:///home/aadish/Documents/typst/FactStamp/template/Extreme_Programming.md)** — Extreme Programming (XP) practices (TDD, Pair Programming, CI/CD).
6. **[`Kanban.md`](file:///home/aadish/Documents/typst/FactStamp/template/Kanban.md)** — Kanban flow, WIP limits, visual queues, & cycle time management.
7. **[`FDD.md`](file:///home/aadish/Documents/typst/FactStamp/template/FDD.md)** — Feature-Driven Development model & feature decomposition.
