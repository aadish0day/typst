# 2.7 Distributed Consensus & Reputation Models

## 2.7.1 Introduction and The Sybil Vulnerability Problem
Decentralized information systems that rely on public crowdsourcing face a profound security vulnerability: **Sybil attacks and partisan brigading**. In a naive voting system (such as Reddit upvotes or Twitter poll majorities), malicious actors can register hundreds of automated bot accounts or organize coordinated off-platform brigades to artificially validate a fraudulent claim or suppress authentic evidence.

Furthermore, naive majority voting treats all participants as epistemically identical: the vote of a seasoned medical researcher evaluating an oncology claim carries the exact same mathematical weight as an anonymous, first-time user voting based on personal ideology.

To maintain unwavering evidentiary integrity while operating without an authoritarian central editor, FactStamp surveyed four distributed governance and consensus models: **Pure Simple Majority**, **Multi-Factor Weighted Quorum**, **Liquid Democracy / Delegation**, and **Blockchain Proof-of-Stake (PoS)**.

---

## 2.7.2 Comparative Evaluation of Consensus Paradigms

| Consensus Paradigm | Decision Mechanism | Core Strengths | Critical Vulnerabilities & Limitations for FactStamp |
| :--- | :--- | :--- | :--- |
| **Pure Simple Majority** | Binary Threshold ($>50\%$ majority wins) | Trivial to calculate; easily understood by general public. | Catastrophically vulnerable to Sybil attacks, click-farms, and partisan collusion; zero accountability for incorrect votes. |
| **Multi-Factor Weighted Quorum** | Algorithmic Score: $C = 0.40A + 0.30R + 0.30S$ | Synthesizes agreement ($A$), verifier track record ($R$), and source credibility ($S$); dynamic anti-Sybil incentives. | Requires calibrated initial reputation parameters; demands independent quorum threshold ($N \ge 3$). |
| **Liquid Democracy / Delegation** | Delegated Transitive Voting Proxy | Allows non-experts to delegate votes to domain experts (e.g., health claims to doctors). | Severe cognitive friction; complex governance overhead; introduces delegate bottlenecks in fast-moving rumors. |
| **Blockchain Proof-of-Stake (PoS)** | Token-Staking on Cryptographic Ledger | Mathematically immutable ledger; high financial cost to mount 51% attacks. | Transaction confirmation latency (12s–2min); requires crypto wallet onboarding; **gas fees violate zero-budget mandate**. |

## 2.7.3 The FactStamp Multi-Factor Weighted Quorum Formulation

FactStamp adopts a **Multi-Factor Weighted Quorum Consensus Model**. Once a claim receives assessments from a minimum quorum of **three independent, authenticated community verifiers ($N \ge 3$)**, the system evaluates the distribution of submitted verdicts and calculates a composite confidence percentage $C \in [0, 100]$:

$$C = (A \times 40\%) + (R \times 30\%) + (S \times 30\%)$$

```text
+--------------------------------------------------------------------------------------------------+
|                            WEIGHTED CONSENSUS FORMULA BREAKDOWN                                  |
+------------------------------+--------+----------------------------------------------------------+
| Component                    | Weight | Mathematical Definition & Normalization                  |
+------------------------------+--------+----------------------------------------------------------+
| Agreement Ratio (A)          | 40%    | A = (N_majority / N_total) * 100                         |
|                              |        | Measures consensus unanimity among quorum verifiers.     |
+------------------------------+--------+----------------------------------------------------------+
| Verifier Reputation (R)      | 30%    | R = (1 / N) * SUM(R_i)                                   |
|                              |        | Normalized mean historical track-record of verifiers.    |
+------------------------------+--------+----------------------------------------------------------+
| Source Credibility Tier (S)  | 30%    | S = (1 / N) * SUM(Q(Domain_i)) * 100                     |
|                              |        | Quantifies institutional authority of primary citations. |
+------------------------------+--------+----------------------------------------------------------+
```

### 1. Agreement Ratio ($A \in [0, 100]$)
Measures the internal alignment of the quorum. If all 3 verifiers agree on *FALSE*, $A = (3/3) \times 100 = 100\%$. If 2 vote *FALSE* and 1 votes *MISLEADING*, $A = (2/3) \times 100 = 66.7\%$.

### 2. Verifier Reputation Index ($R \in [0, 100]$)
Every authenticated verifier possesses a dynamic reputation score $R_i$:
- Initialized at **$R_0 = 50$** upon account creation.
- Bounded strictly within the interval $[0, 100]$.
- The quorum score $R$ represents the arithmetic mean of the participating verifiers' scores:
  
  $$R = \frac{1}{N} \sum_{i=1}^{N} R_i$$

### 3. Source Credibility Tier ($S \in [0, 100]$)
Every verification submission mandates an authoritative citation URL. Domain names are scored according to an institutional trust hierarchy $Q(\text{Domain}) \in [0.0, 1.0]$:
- **Tier 1 ($Q = 1.0$, Score = 100):** Government gazettes (`.gov.in`, `.nic.in`), peer-reviewed medical journals (`nih.gov`, `thelancet.com`), accredited multilateral organizations (`who.int`), and judicial portals (`sci.gov.in`).
- **Tier 2 ($Q = 0.70$, Score = 70):** Mainstream accredited journalistic outlets (The Hindu, Indian Express, BBC, Reuters) and IFCN-signatory fact-checking desks (AltNews, BOOM Live).
- **Tier 3 ($Q = 0.30$, Score = 30):** General blogs, corporate press releases, social media accounts, or unverified secondary web links.

The aggregate source score $S$ represents the normalized average credibility of the submitted citation links:
$$S = \frac{1}{N} \sum_{i=1}^{N} Q(\text{Domain}_i) \times 100$$

## 2.7.4 Dynamic Reputation Update & Anti-Sybil Defense

To align individual self-interest with objective truth, FactStamp implements an automated **post-consensus reputation adjustment feedback loop**:

```text
[Quorum Reaches N >= 3 Verifications]
                 │
                 ├── Calculate Confidence: C = 0.40A + 0.30R + 0.30S
                 │
                 ├── If C >= 70%: Certified Consensus Finalized!
                 │         │
                 │         ├── Aligned Verifiers (Voted with Consensus):
                 │         │     R_new = min(100, R_current + 2)
                 │         │
                 │         └── Outlier Verifiers (Voted against Consensus):
                 │               R_new = max(0, R_current - 3)
                 │
                 └── If C < 70%: Status set to CONTESTED (Pending additional reviews)
```

1. **Consensus Certification Threshold:** A claim is certified with a definitive verdict only when composite confidence reaches **$C \ge 70\%$**.
2. **Asymmetric Reward/Penalty Mechanics:** Verifiers whose assessments match the validated consensus gain **$+2$ points**. Verifiers submitting negligent, bad-faith, or fraudulent outlier votes lose **$-3$ points**. This asymmetric penalty ensures that random guessing or Sybil spamming degrades reputation faster than it accumulates.
3. **Anti-Self-Verification Constraint:** Cloud Firestore v12.17.0 security rules strictly enforce:
   ```javascript
   allow create: if request.auth.uid != get(/databases/$(database)/documents/claims/$(claimId)).data.submittedBy;
   ```
   A user is programmatically barred from verifying a claim they originally submitted, completely eliminating self-verification loops.

## 2.7.5 Architectural Decision Record (ADR)

* **Title:** ADR-07: Formulation of Multi-Factor Weighted Quorum Consensus Model
* **Status:** Accepted and Fully Implemented.
* **Context:** FactStamp requires a consensus mechanism that prevents Sybil collusion, rewards credible evidence, and operates with sub-second computation without incurring blockchain transaction fees.
* **Decision:** Adopt an algorithmic multi-factor weighted consensus model ($C = 0.40A + 0.30R + 0.30S$) requiring an independent 3-verifier quorum ($N \ge 3$), supplemented by an asymmetric reputation update loop ($+2$/$-3$).
* **Consequences:** Successfully neutralizes bot manipulation and partisan voting rings; prioritizes peer-reviewed and governmental citations; establishes an accountable, meritocratic community verification corps.
